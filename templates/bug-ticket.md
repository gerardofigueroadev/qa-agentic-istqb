# Template — Bug Report (mínimo viable)

> Lo único que el QA/reporter debe llenar. El resto lo reconstruye el agente
> cruzando Sentry + explorando la app.

- **Título:** [módulo] + comportamiento observado
  - Ej: `[Checkout] No se puede comprar entradas para La Última Función`
- **Qué pasó / qué se esperaba:** 2 líneas máximo.
- **Entorno:** URL + usuario de prueba (o real, anonimizado).
- **Link a Sentry:** issue o, si no se tiene, fecha/hora aproximada del error. ← LA CLAVE
- **Severidad percibida:** Alta / Media / Baja.
